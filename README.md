# COMPANY v1.0.0

منصة عربية أولية لإدارة عدة شركات من واجهة واحدة.

## ما يعمل الآن
- لوحة نظرة عامة.
- مساحات محلية متعددة بأسماء شركات مختلفة.
- إدارة سجلات المهام والموظفين والعملاء والمبيعات والمخزون والمالية.
- تقارير أولية.
- تصدير نسخة احتياطية JSON.
- تصميم متجاوب للهاتف والكمبيوتر.
- أساس تطبيق ويب تقدمي PWA مع manifest وservice worker.

## تنبيه أمني
هذه نسخة واجهة تجريبية تستخدم Local Storage؛ لا يوجد تسجيل دخول أو مزامنة أو عزل آمن بين المستخدمين. لا تدخل بيانات حقيقية أو حساسة. قبل الاستخدام الفعلي يجب ربط قاعدة بيانات ومصادقة وتفعيل RLS واختبار عزل الشركات.

## التشغيل
انشر الملفات الثابتة على استضافة HTTPS مثل Cloudflare Pages أو GitHub Pages.

# COMPANY v1.1.x — تجربة أولية

منصة عربية لإدارة مساحات شركات متعددة، بواجهة RTL ومصادقة Supabase.

## الموجود حالياً
- تسجيل حساب وتسجيل دخول بالبريد وكلمة المرور عبر Supabase Auth.
- إنشاء شركة وإضافة مالكها الأول.
- تحميل الشركات التي للمستخدم عضوية فيها.
- إدارة المهام داخل الشركة عبر قاعدة Supabase.
- أقسام الموظفين والعملاء والمبيعات والمخزون والمالية موجودة كواجهات محلية على الجهاز فقط.
- لوحة ملخص، تقارير أولية، تصدير بيانات محلية، وواجهة PWA متجاوبة.
- سياسات RLS مفعّلة على جداول الشركات والعضويات والمهام.

## مهم قبل التجربة
هذه نسخة اختبار وليست جاهزة للإنتاج. لا تستخدم بيانات مالية أو شخصية حقيقية. لم يثبت بعد اختبار الدخول وإنشاء الشركة والمهام من متصفح فعلي، كما لم يثبت اختبار عزل البيانات بين حسابين مختلفين. لا توجد بعد دعوات أعضاء أو إدارة أدوار من الواجهة.

## الإعداد والنشر
1. استضافة الملفات الثابتة على HTTPS.
2. تأكد من أن ملف supabase-config.js يحتوي فقط على رابط المشروع ومفتاح publishable.
3. في Supabase Auth اضبط Site URL و Redirect URLs على عنوان النشر.
4. لا تضع service_role أو أي Secret Key في ملفات الواجهة.
5. اختبر بحسابين منفصلين وشركتين منفصلتين قبل إدخال بيانات حقيقية.

## قاعدة البيانات
ملف supabase/schema.sql يوثق مخطط الأساس. توجد إصلاحات وفهارس إضافية طُبقت على مشروع COMPANY، ويجب حفظها كمهاجرات مستقلة عند مزامنة المخطط لاحقاً.

## الاستضافة
تم تجهيز المشروع للاستضافة الثابتة على Vercel. يلزم ربط حساب Vercel قبل تنفيذ النشر وإرجاع رابط تجربة حي.
